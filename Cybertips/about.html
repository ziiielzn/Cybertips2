Our Journey

March 5-23, 2025: The Blueprint Stage

We planned to design a cybersecurity website that's clean, simple, and actually useful. We mapped out the structure, layout, and user interface using Figma to create a visual prototype. We started with small and basic topics for cyber tips with only 50% working and the rest were under development.

April 10-25, 2025: Design to Code Development

We had the Figma designs locked in and had begun translating them into real code. We changed the UI Design into quite appealing for the UX. With our visual plans ready, we dove headfirst into hard coding the entire site. started turning Figma frames into HTML, CSS, and JavaScript. We also started populating the site with researched cybersecurity tips—short, simple, and useful.

May 2-23, 2025: The Final Touches

We completed feature development fixed bugs, cleaned up the UI, and improved overall performance. Added finishing touches to content, visuals, and the other cyber tips content for our website.
